# experiments/ — архив отработанных экспериментов

Одноразовые диагностики из прошлых раундов отладки. Оставлены для истории
(git-история всё равно их хранит), редко требуются. Если какие-то станут
нужны постоянно — переносите наверх, в `tools/`.

Актуальные инструменты лежат в `tools/`:

| Скрипт | Назначение |
|---|---|
| `..\wake_eval.py` | FRR/FAR wake word по датасету (блоки, условия, дистанция) |
| `..\verify_all.py` | wake + команды на всём датасете |
| `..\baseline.py` | общие helpers для verify_all (GigaAM, ActionRouter) |
| `..\record_dataset\` | запись и QC датасета |

## Что здесь

| Скрипт | Чем заменён / когда был нужен |
|---|---|
| `wake_real_eval.py` | `tools/wake_eval.py` — общая версия с CLI и разбивками |
| `wake_experiments.py` | подбор `wake_confusables`, итог зафиксирован в config.json |
| `wake_chunks.py` | чанки и текст Vosk для пропусков (правки в `allowed_errors`) |
| `wake_debug.py` | диагностика одного файла по уровням громкости |
| `check_fixes.py` | проверка правок текста на сохранённых baseline-текстах, теперь покрыто tests |
| `live_gap_test.py` | живой путь без очистки микрофона, разовая проверка |
| `beep_experiment.py` | влияет ли beep на живую команду, разовая проверка |
| `level_profile.py` | профиль громкости 100 мс по файлам, заменён QC-отчётом |
| `show_baseline.py` | печатает старый `tools/baseline_results.json` |

Запуск из корня репозитория:
```
.venv\Scripts\python.exe tools\experiments\<имя>.py
```
Путь к модулям `app/` скрипты пересчитывают сами (от своей папки).
