# Облачная LLM

Ответы на вопросы, новости и рассуждения идут через ProxyAPI. Локальная
модель в ответах не участвует: она осталась только как опциональный
планировщик команд (`local_planner`).

## Модели

| Роль | Модель | Цена вход/выход, ₽ за 1M | Почему |
|---|---|---|---|
| Основная | `anthropic/claude-haiku-5-5` | 30 / 150 | стабильно закрывает базовые вопросы, новости и рассуждения |
| Запасная | `xiaomi/mimo-v2.6-flash` | 18,95 / 37,89 | дешевле, быстро отвечает; включается при сбое основной |

Claude отвечает на базовый вопрос за 1,3–1,9 с, на новостную сводку — за
5–8 с и даёт 3–4 пункта, как и просит промпт. MiMo на новостях даёт 3 пункта
за 2–5,6 с, но на простых вопросах иногда доходит до 9 с и делает опечатки,
поэтому она только запасная.

## Поведение

- `CloudLLM.answer()` — единственный метод ответов.
- При ошибке, пустом ответе или таймауте основная модель сменяется запасной.
- Ошибки 429/5xx повторяются (`retries`), 4xx и таймауты сразу уходят к
  запасной модели.
- При недоступности обеих моделей `QAService` возвращает ошибку. Отката на
  локальную модель нет.
- Для рассуждающих моделей используется `max_completion_tokens` с нижним
  порогом 2000: иначе reasoning съедает лимит и ответ приходит пустым.
- `reasoning_effort: minimal` — самый быстрый и дешёвый режим; Claude всё
  равно тратит 600–1000 токенов на скрытые размышления.

## Конфиг

```json
"cloud_llm": {
  "enabled": true,
  "base_url": "https://api.proxyapi.ru/v1",
  "api_key": "sk-...",
  "model": "anthropic/claude-haiku-5-5",
  "fallback_models": ["xiaomi/mimo-v2.6-flash"],
  "reasoning_effort": "minimal",
  "max_completion_tokens": 2000,
  "temperature": 0.2,
  "timeout_sec": 90,
  "retries": 2
}
```

Пустой `api_key` означает «взять `tts.api_key`»: оба сервиса работают через
ProxyAPI.

## Стоимость

При 30 запросах в день — примерно 75–100 ₽/мес на Claude. Одна новостная
сводка ≈ 15 копеек, обычный ответ ≈ 5 копеек. Запасная MiMo вчетверо дешевле,
но включается редко.

## Проверка

```powershell
python -m app.doctor
```

Блок «Облачная LLM» показывает адрес, основную и запасную модели и наличие
ключа. Сетевой запрос диагностика не делает, чтобы не тратить деньги.
