# Фразы для предзаписи (Fish Audio S2 Pro)

Предзаписанные фразы нужны, чтобы ассистент отвечал моментально: файл читается
с диска и играет сразу, без запроса к API.

Динамические ответы (новости, погода, ответы на вопросы) озвучиваются через API
на лету и в этот список не входят.

## Формат файлов

- **WAV, 44.1 кГц, моно, 16 бит PCM.** Играется напрямую через `sounddevice`,
  без декодеров и зависимостей.
- Длительность 0.5–1.5 с. Ведущую и хвостовую тишину обрезать до ~50 мс,
  иначе будет ощутимая пауза перед ответом.
- Громкость одинаковая у всех файлов, без клиппинга.
- Имя файла: `<id>.wav`, например `done_1.wav`. Путь: `assets/phrases/`.
- Текст произносить ровно как в таблице, без добавок.

Альтернатива: можно отдать MP3 — тогда добавлю в проект `soundfile`
(он декодирует MP3), но WAV проще и стартует быстрее.

## Как делаем разнообразие

1. Внутри категории выбирается случайный вариант, но не тот же, что звучал
   в прошлый раз (и не из последних двух).
2. Частые категории (`done`, `wake`, `ack`) имеют больше вариантов.
3. Дополнительно можно записать 2–3 фразы с чуть другой интонацией
   (например, `done_1_alt` с `speed: 1.05`), чтобы тембр не приедался.
4. Эмоциональные пометки Fish Audio вроде `(радостно)` можно добавить
   к 1–2 вариантам, но только после прослушивания — не все модели их
   корректно понимают.

## Что НЕ предзаписываем

- Текст ответа на вопрос, сводку новостей, погоду — они уникальны.
- Названия сайтов, треков, городов и чисел в подтверждениях.
- Для таких случаев играем короткое «Выполняю» / «Готово», а детали
  остаются в тосте и во вкладке Chrome.
